## Image transparency
The site discloses that concept/design imagery may be AI-generated and does not depict actual inventory. Product listings should use genuine item photos and accurate descriptions.

## Deploy
This config targets the separate Firebase Hosting site `wild-west-gemstones-10011` in project `veralynndegrawportfolio`. Verify the site ID and Firebase project before deploying:
`firebase deploy --only hosting --project veralynndegrawportfolio`

The `mailto:` inquiry form opens the visitor's email client. It does not upload files or store submissions server-side.
